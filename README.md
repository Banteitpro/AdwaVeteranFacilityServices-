# Adwa Veteran Facility Services

Adwa Veteran Facility Services provides professional facility maintenance and support services tailored to veterans and veteran-owned organizations. This repository hosts the website for our business and contains the static site files used to present our services, contact information, and company details.

## About Us
Adwa Veteran Facility Services is dedicated to delivering reliable, respectful, and high-quality facility services that honor the needs of veterans. Our team is experienced in building maintenance, cleaning, repairs, and facilities management with a focus on safety, accessibility, and integrity.

## Services
- Building maintenance and repairs
- Janitorial and deep-cleaning services
- Groundskeeping and landscape maintenance
- HVAC, plumbing, and electrical coordination
- Safety inspections and accessibility improvements
- Preventive maintenance programs

## Website
This repository contains the static website files used to represent our business online. The site is designed for simplicity and clarity, with contact details and an overview of our services.

Main files:
- `index.html.html` — Primary site HTML file (rename to `index.html` if needed for deployment)
- `CNAME` — Custom domain configuration

## Technologies
The site is built as a static HTML site and can be hosted on platforms such as GitHub Pages, Netlify, or any static file hosting service.

## Deployment
To publish the site on GitHub Pages:
1. Rename `index.html.html` to `index.html` if your deployment expects exactly that filename.
2. Ensure the `CNAME` file contains your custom domain if using one.
3. Enable GitHub Pages from the repository Settings and select the branch containing the site files.

For Netlify or similar hosts, connect the repository and configure the build/deploy settings as a static site with no build command required.

## Local Testing
To preview the site locally, open `index.html.html` (or `index.html` after renaming) in your web browser. For a simple local server:

- Using Python 3:
  python -m http.server 8000
  Then open http://localhost:8000 in your browser.
